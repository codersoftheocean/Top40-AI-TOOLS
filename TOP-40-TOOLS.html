Ground rules

USE AI / KEEP YOUR JUDGEMENT
01 / Verify

AI can be confidently wrong. Check facts, citations and generated code before relying on them.

02 / Disclose

Follow your college, workplace or client rules for AI-assisted work.

03 / Guard data

Never paste passwords, API keys or private datasets without understanding the service's data handling.

04 / Understand it

If you cannot explain the output, do not blindly ship it or defend it in an interview.

05 / Commit often

Use Git when AI edits code so changes remain reviewable and reversible.

06 / Check prices

Plans and features can change. Confirm current details on the official site.
